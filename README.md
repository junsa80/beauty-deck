# 미녀 덱: 밤의 여왕 (v1.0.0)

슬레이 더 스파이어 스타일의 **모바일 덱빌딩 로그라이트** 웹앱입니다. 순수 HTML/CSS/JS라 빌드 없이 돌아가고, 폰 세로 화면(360~430px)에 맞춰 만들었습니다.
**모든 등장인물은 20대 이상의 성인 여성**이고, 노출·교복 같은 요소는 없습니다.

▶ **플레이:** https://junsa80.github.io/beauty-deck/ (홈 화면에 추가하면 앱처럼 실행되고, 오프라인에서도 열립니다)

## 메타 진행 · 해금
- **아리아**: 2막 보스 「밤의 여왕 벨리타」를 한 번 이기면 합류합니다.
- **전설 카드**: 업적을 달성하면 보상 풀에 들어옵니다. 진홍의 일섬(한 방 40 이상), 초신성(한 턴 10장), 천 개의 독침(중독 30), 절대 성역(방어도 50), 앙코르(엘리트 10회).
- **갤러리**: 히로인별 클리어, 보스 격파, 승천 5·10, 엘리트 10회, 4명 모두 클리어로 열립니다.
- **승천**: 클리어할 때마다 한 단계씩 열립니다. 단계가 쌓일수록 엘리트·일반 적 체력, 적 공격력, 회복량, 최대 체력, 상처 카드, 보스 힘 같은 페널티가 붙습니다.

## 조작 (모바일)
- 카드를 **터치해서 고르고**, 적을 터치하면 사용합니다. 적이 하나뿐이거나 대상이 필요 없으면 카드를 한 번 더 터치하세요.
- 내 이름 옆에 **🗡️들어올 피해 − 🛡️방어도 → 실제 피해**가 나옵니다.
- 적을 터치하면 다음 행동, 상태, 기술 목록을 보여 줍니다. 카드나 일러스트를 터치하면 **크게 보기**(9:16 전체 그림)가 열립니다.
- ☰ 메뉴에서 덱, 도감, 도움말, 설정(효과음·진동·움직임 줄이기·빠른 연출), 포기를 고를 수 있습니다.

## 일러스트
- 실제 그림이 없는 칸은 `art.js`가 **key마다 다른 9:16 SVG 일러스트**(히로인 실루엣, 색, 문양)를 즉석에서 그립니다. 그래서 그림 없이도 모든 화면이 완성된 상태로 보입니다.
- 실제 그림 슬롯은 **180칸**입니다: 히로인 12, 적 29, 카드 111, 갤러리 12, 이벤트 16.
  1. `node tools/art_prompts.js`를 실행하면 `art/ART_PROMPTS.md`와 `art/prompts.json`이 나옵니다. 16:9 트립틱 60장 분량이고, 한 장에 세로 패널 3개가 들어갑니다.
  2. 생성한 트립틱을 `art/incoming/batch_###.png`로 저장합니다. 한 장짜리라면 `card_s_bash.png`처럼 이름을 붙입니다.
  3. `python3 tools/ingest_art.py`를 실행합니다. 늘리지 않고 잘라서 **540×960 webp(약 60~120KB)**로 `img/`에 저장하고, `artmap.js`도 자동으로 갱신합니다.
  - 그림은 `loading="lazy"`로 불러오고, 서비스 워커가 캐시해 둡니다.

## 파일 구조
```
index.html          진입점 (artmap → art → data → engine → ui 순서로 로드)
style.css           스타일 (모바일 세로 우선, 움직임 줄이기 지원)
artmap.js           실제 일러스트 목록 (ingest_art.py가 자동 생성)
art.js              절차적 일러스트 + 실제 그림 연결
data.js             ★ 콘텐츠: 히로인/상태/계열/카드/시작덱/막/적/조우/유물/물약/이벤트/업적/갤러리/승천
engine.js           게임 규칙 (DOM 없음, Node에서 실행 가능). 상태는 run 객체 하나 = JSON 저장
ui.js               화면, 터치 입력, 연출, 효과음/진동, 튜토리얼, 도감, 메타 저장
manifest.webmanifest, sw.js, icons/   PWA
tools/build.js      단일 파일 빌드 → dist/beauty-deck.html
tools/art_prompts.js, tools/ingest_art.py   일러스트 파이프라인
test/sim.js         헤드리스 시뮬레이션 (무작위 봇 = 크래시/소프트락 탐지, 똑똑한 봇 = 밸런스)
test/ui-smoke.js    헤드리스 크롬 모바일 터치로 한 판 진행 (GOD=1 이면 종막까지 완주)
test/ui-scenes.js   주요 장면 스크린샷 (390×844, 360×780)
```
- 엔진 함수(`playCard`, `endTurn`, `chooseNode`, `takeBossRelic` 등)는 `run`을 바꾸고 `{ok, reason}`을 돌려줍니다. 화면은 `run.screen` 값으로 정해집니다.
- 연출은 엔진이 `run.fx`에 이벤트(`dmg`, `block`, `say`, `phase`, `act`, `revive` 등)를 쌓으면 `ui.js`의 `playFx`가 받아서 처리합니다.
- 난수는 시드 기반(`run.rng`)이라 저장하고 다시 불러와도 같은 흐름으로 이어집니다.
- 저장 키: `beautydeck.run.v2`(진행 중인 원정), `beautydeck.meta.v2`(업적·도감·기록, v0.1 기록 자동 이전), `beautydeck.settings.v1`
- 저장은 **이 기기 localStorage만** (클라우드 동기화 없음). 설정에서 JSON 백업 내보내기/가져오기 가능. 가져올 때 로컬이 더 새롭거나 기록이 더 많으면 덮어쓰기 경고를 띄움 (v1.1.1).

## 테스트
```bash
node test/sim.js 300                 # 히로인별 300판씩 (무작위 봇 + 똑똑한 봇)
ASC=10 node test/sim.js 100          # 승천 10
node tools/build.js                  # dist/beauty-deck.html
python3 -m http.server 8765 &        # 로컬 서버
NODE_PATH=<puppeteer-core 위치>/node_modules URL=http://127.0.0.1:8765/ VP=360x780 node test/ui-smoke.js
NODE_PATH=... URL=http://127.0.0.1:8765/ node test/ui-scenes.js
```
**밸런스 (똑똑한 봇, 히로인별 300판)**: 승천 0에서 세라 36%, 루나 33%, 유키 32%를 클리어합니다. 해금 보상 캐릭터 아리아는 58%로 더 쉽습니다. 승천 5에서는 12~13%(아리아 33%), 승천 10에서는 1~3%(아리아 8%)입니다. 무작위 봇을 포함해 수천 판을 돌리는 동안 크래시, 소프트락, 불변식 위반은 0건이었습니다.

## 콘텐츠 추가
- 카드: `data.js`의 `C(id, 이름, 클래스, 타입, 희귀도, 비용, 히로인, [계열], 아이콘, [효과], {강화}, {기타})`. 설명문과 강화 비교는 효과 정의에서 자동으로 만들어집니다(`describe`, `upgradeDiff`).
- 적: `ENEMIES`에 `moves`와 `ai`(cycle/random)를 넣고, 보스라면 `phases`를 추가한 뒤 `ENCOUNTERS[막]`에 등록합니다.
- 이벤트: `EVENTS`에 `options[].fx`(gold, hp, maxHp, heal, healPct, relic, card, potion, upgrade, remove, dup, transform, wound, fight 등)를 지정합니다. `acts`로 등장할 막을 정할 수 있습니다.
