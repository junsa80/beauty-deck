> 다른 AI가 이어받을 때는 먼저 `AI_START.md`를 읽으세요.

## 히로인 기믹 요약 (v1.3.2)
히로인 선택 화면과 프로필에 짧은 기믹 설명(`data.js` `STARTERS[].mech`)이 나옵니다. 내용은 engine.js 동작 기준입니다.
- 세라: 힘만큼 공격 피해 증가. 마리엘: 인형 최대 3체, 피해는 방어도 → 맨 앞 인형 → 체력, 턴 끝에 인형마다 무작위 적 공격, 3체일 때 더 세우면 맨 앞 인형 체력 증가.
- 세레나: 카드를 낼 때마다 🌒초승→🌓반달→🌕보름→🌑그믐, 카드를 **낼 때의** 위상이 배지와 같으면 추가 효과, 그믐→초승이 한 바퀴.
- 오데트: 보존 카드는 턴 끝에 손에 남고 각주 +1, 카드를 내면 각주 0.

## v1.3 새 히로인
- **마리엘 (인형사, 23)**: 카드로 **인형**(🪆)을 세움. 적 공격은 방어도 → 맨 앞 인형 → 체력 순으로 맞음. 턴 끝에 인형마다 공격(+인형술). 희생 카드는 인형을 부숴 큰 효과. 시작 유물 은빛 골무(전투 시작 시 인형 체력 5·공격 2), Lv5 패시브: 보스 전투 시작 시 도도(체력 6·공격 2).
- **세레나 (달의 무희, 22)**: 달 위상 🌒초승→🌓반달→🌕보름→🌑그믐 이 카드를 낼 때마다 한 칸 진행. 카드마다 맞는 위상에서 내면 추가 효과(카드에 위상 배지). 한 바퀴 돌면 달의 순환 피해. 시작 유물 초승달 비녀(한 바퀴마다 방어도 3), Lv5 패시브: 매 턴 처음 위상이 바뀔 때 방어도 3.
- **오데트 (사서, 24)**: **보존** 카드는 턴이 끝나도 손에 남고 **각주**(📑)가 1씩 쌓여 강해짐. 고를 것 없이 내기만 하면 되는 가벼운 조작(선택 창 없음, 한 화면에 다 보임). 시작 유물 놋쇠 열쇠, Lv5 패시브: 엘리트·보스 전투 시작 시 각주 2의 「낭독」 1장.
- 해금 결정: 세 명 모두 **처음부터 선택 가능**(새 히로인은 Lv1에서 시작). 기존 저장은 형식 변경 없이 그대로 열림.
- 히로인 레벨 구간은 기존 0/100/…/3200 그대로 씀(기획안의 0/16/40/80/140은 이 코드에 없는 수치라 쓰지 않음).

## 일러스트
- 실제 그림이 없는 칸은 `art.js`가 **key마다 다른 9:16 SVG 일러스트**(히로인 실루엣, 색, 문양)를 즉석에서 그립니다. 그래서 그림 없이도 모든 화면이 완성된 상태로 보입니다.
- 실제 그림 슬롯은 **240칸**이고 전부 채워져 있습니다(artmap.js 기준): 히로인 15, 적 29, 카드 168, 갤러리 12, 이벤트 16.
  1. `node tools/art_prompts.js`를 실행하면 `art/ART_PROMPTS.md`와 `art/prompts.json`이 나옵니다. 16:9 트립틱 60장 분량이고, 한 장에 세로 패널 3개가 들어갑니다.
  2. 생성한 트립틱을 `art/incoming/batch_###.png`로 저장합니다. 한 장짜리라면 `card_s_bash.png`처럼 이름을 붙입니다.
  3. `python3 tools/ingest_art.py`를 실행합니다. 늘리지 않고 잘라서 **540×960 webp(약 60~120KB)**로 `img/`에 저장하고, `artmap.js`도 자동으로 갱신합니다.
  - **숙련 카드 12장(v1.2.1)**: `tools/mastery_art.js`가 같은 히로인의 실제 일러스트를 카드마다 다르게 잘라 색보정하고, 카드 효과 SVG(꽃잎 참격·혜성·서리·독침·초승달·등불·방패 문양 등)와 금빛 숙련 문장을 겹쳐 540×960 webp로 굽고 `artmap.js`에 등록합니다. `NODE_PATH=/tmp/pt/node_modules node tools/mastery_art.js`
  - 그림은 `loading="lazy"`로 불러오고, 서비스 워커가 캐시해 둡니다.

- 엔진 함수(`playCard`, `endTurn`, `chooseNode`, `takeBossRelic` 등)는 `run`을 바꾸고 `{ok, reason}`을 돌려줍니다. 화면은 `run.screen` 값으로 정해집니다.
- 연출은 엔진이 `run.fx`에 이벤트(`dmg`, `block`, `say`, `phase`, `act`, `revive` 등)를 쌓으면 `ui.js`의 `playFx`가 받아서 처리합니다.
- 난수는 시드 기반(`run.rng`)이라 저장하고 다시 불러와도 같은 흐름으로 이어집니다.
- 저장 키: `beautydeck.run.v2`(진행 중인 원정), `beautydeck.meta.v2`(업적·도감·기록·히로인 경험치, 내부 형식 v3), `beautydeck.settings.v1`(대사 켜기·시작 선택 포함)

- 저장은 **이 기기 localStorage만** (클라우드 동기화 없음). 설정에서 JSON 백업 내보내기/가져오기 가능. 가져올 때 로컬이 더 새롭거나 기록이 더 많으면 덮어쓰기 경고를 띄움 (v1.1.1).
