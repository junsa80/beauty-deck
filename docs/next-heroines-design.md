## A안. 마리엘 — 실의 인형사 (소환형) ★추천
- **겉모습/복장**: 26세. 짙은 와인색 땋은 반묶음 머리, 회색 눈, 둥근 안경. 목까지 단추가 채워진 짙은 녹색 공방 코트, 가죽 앞치마, 손가락마다 은색 골무와 은실. 허리에 작은 공구 벨트. 곁에 사람 크기 절반의 나무 인형 "도도"(기사 모양).
- **역할**: 원정대의 "공방 담당". 망가진 장비를 고치고, 인형으로 앞줄을 대신 선다.
- **새 메커니즘: 인형(소환 유닛)**. 전투 중 최대 3체의 인형을 히로인 앞에 세움. 인형은 체력을 갖고, **적의 단일 공격을 앞에서부터 대신 맞음**, 턴 종료 시 각자 행동(공격/방어/버프). 엔진에 `run.combat.allies[]`와 턴 종료 처리, 적 공격 대상 분기가 필요(적 `puppet` 소환 로직이 이미 있어 참고 가능).
- **빌드 축 3개 (서로 다른 덱이 나옴)**
  1. *군단*: 값싼 인형을 많이 세우고 "인형 수만큼" 효과(합창 공격).
  2. *희생*: 인형을 일부러 부숴서 큰 효과(폭발·드로우·에너지). 세라의 피의 각오와 비슷한 손익 판단이지만 내 체력이 아니라 인형을 씀.
  3. *정교한 한 체*: 인형 하나에 강화를 몰아 줘서 "두 번째 히로인"처럼 키움(도도 강화).
- **패시브(Lv5) "공방의 손"**: 전투 시작 시 도도(체력 6, 턴 종료 시 피해 3) 1체 소환.
- **전용 12장 스케치** (cls `puppet`, 아키타입 `legion`/`sacrifice`/`craft`/`string`)
  1. 인형 세우기 (0코, 시작) 체력 4 인형 소환.
  2. 실 꿰기 (1코, 시작) 방어도 5, 인형 하나 체력 +3.
  3. 합창 (1코, 일반) 인형 수×4 피해.
  4. 대역 (1코, 일반) 이번 턴 모든 공격을 맨 앞 인형이 받음 + 방어도 3.
  5. 분해 (0코, 일반) 인형 1체 파괴 → 카드 2장, 에너지 1.
  6. 불꽃 심장 (1코, 고급) 인형 1체 파괴 → 모든 적에게 그 인형 최대 체력만큼 피해.
  7. 조종실 (2코, 파워) 턴 종료 시 인형이 한 번 더 행동.
  8. 실 끊기 (1코, 고급) 적의 다음 행동을 "약한 공격"으로 바꿈(의도 조작 1회).
  9. 도도 개량 (1코, 파워) 도도 공격 +2, 체력 +4. 중첩.
  10. 숙련① 은실 그물 (Lv2) 모든 적 약화 1, 인형 수만큼 방어도.
  11. 숙련② 커튼콜 (Lv4) 인형 전원 즉시 행동 1회.
  12. 숙련③ 마지막 무대 (Lv7, 희귀, 소멸) 파괴된 인형을 전부 체력 절반으로 복구.
- **레벨 1~10**: Lv2 스토리1+은실 그물 · Lv3 대안 유물 "낡은 재봉 상자"(전투 시작 인형 2체, 대신 도도 없음) · Lv4 스토리2+커튼콜 · Lv5 패시브 공방의 손 · Lv6 스토리3+덱 변형 "희생형"(실 꿰기 2장 → 분해·불꽃 심장) · Lv7 마지막 무대 · Lv8 스토리4+칭호 "실을 잇는 사람" · Lv9 시작 물약 · Lv10 스토리5+칭호 "닉스의 무대를 닫은 인형사"+금테.
- **스토리 5장 (기존 설정 연결)**
  1. *부서진 기사 인형* — 루벨 마을 출신 공방 장인. 3년 전 아리아가 마을 입구를 막던 밤, 아리아의 방패를 본떠 도도를 만듦. 아리아와 첫 만남.
  2. *클로에의 실* — 2막 적 인형술사 클로에가 같은 공방의 후배였음. 클로에가 닉스의 성에 간 이유(인형에 "깨어 있는 밤"을 담으려고)를 들음.
  3. *숲의 목각 인형* — 모르가나 오두막의 목각 인형들(유키 2장)을 보고, 그림자 일족 아이들 인형을 고쳐 줌. 유키와의 장.
  4. *별을 꿰매는 법* — 셀레스의 첨탑에서 "별자리 실"로 깨진 새벽별 지도를 꿰맴. 루나·셀레스 연결.
  5. *막을 내리는 사람* — 닉스는 세상을 "끝나지 않는 연극"으로 만들려 했음. 마리엘은 인형들과 함께 막을 내리고, 루벨의 잠든 아이들(미라 포함)에게 도도를 맡김.
- **대사 3줄**: "앞줄은 도도가 설게. 넌 내 뒤에서 숨 쉬어." / "부서지는 건 괜찮아. 다시 꿰매면 되니까." / "막이 내려야 박수도 치지. 닉스, 이제 퇴장이야."
- **구현 난이도**: 높음(동맹 유닛 + 화면 배치 + 봇 휴리스틱). 대신 빌드 다양성이 가장 큼.

## B안. 세레나 — 달 위상 무희검사 (자세 전환형)
- **겉모습/복장**: 25세. 은백색 긴 생머리를 낮게 묶고 초승달 비녀. 남색 눈. 무릎 아래까지 오는 남색·은색 긴 무희 외투에 바지, 허리 장식끈, 양손 곡도 두 자루.
- **역할**: 닉스의 옛 궁정 무희. 원정대의 "흐름 담당".
- **새 메커니즘: 달 위상**. 카드를 낼 때마다 위상이 초승 → 반달 → 보름 → 그믐 순으로 1칸 이동. 카드마다 "보름이면 피해 2배", "그믐이면 0코" 같은 위상 보너스. 위상을 건너뛰거나 고정하는 카드로 순서를 맞추는 퍼즐형. (세라의 검무 trance는 "공격마다 방어"일 뿐, 순서 퍼즐은 없음.)
- **빌드 축**: 보름 폭딜(위상 맞춰 큰 한 방) / 그믐 순환(0코 연쇄, 드로우) / 위상 고정(한 위상에 머물며 안정 운영).
- **패시브(Lv5) "밤하늘의 박자"**: 매 턴 첫 위상 이동 시 방어도 3.
- **전용 12장 스케치**: 초승 베기, 반달 스텝, 보름 일섬, 그믐 숨결, 위상 건너뛰기, 달 멈춤(파워, 위상 고정 1턴), 월식(위상 무관 피해 = 이번 턴 위상 이동 수×5), 은빛 회전(광역), 조수 간만(손패 위상 카드 비용 -1), 달무리(방어), 숙련 3장(별비 무도 / 잔월 / 닉스의 마지막 곡).
- **레벨 1~10**: 같은 틀. Lv3 대안 유물 "깨진 은반지"(시작 위상 보름), Lv6 덱 변형 "그믐 순환형".
- **스토리 5장**: 1) 닉스의 궁정을 떠난 무희 2) 벨리타와 같은 성에서 다른 밤을 지킨 사이 3) 셀레스가 위상 계산을 가르쳐 줌(루나와 사제 관계 공유) 4) 모르가나 숲의 달맞이 축제 5) 닉스 앞에서 마지막 춤, 해가 뜨는 위상 "여명"이 처음 생김.
- **대사**: "박자 놓치지 마. 다음이 보름이야." / "달은 기울어도 사라지지 않아." / "닉스 님, 이 곡은 아침에 끝나요."
- **구현 난이도**: 중간(전투 상태값 하나 + 카드 조건). UI는 위상 아이콘 하나면 됨.

## C안. 오데트 — 서고의 기록관 (덱 순서·예약형)
- **겉모습/복장**: 29세. 짧은 갈색 단발에 깃펜 꽂은 머리띠, 녹갈색 눈. 단정한 짙은 갈색 학자 코트, 하얀 셔츠, 허리에 두꺼운 책과 열쇠 꾸러미.
- **역할**: 셀레스 첨탑 서고의 기록관. 원정대의 "계획 담당".
- **새 메커니즘: 예약(보존)·각주**. 손패를 턴 끝에 최대 2장 남길 수 있고, 남긴 카드는 턴마다 "각주" +1(효과 강화). 뽑을 더미 맨 위를 보고 순서를 바꾸는 카드. 루나(드로우 양)와 달리 "무엇을 언제" 쓰는지를 조작.
- **빌드 축**: 각주 축적(한 장을 오래 키워 큰 효과) / 미리 보기 조작(덱 위 정렬로 매 턴 최적 손패) / 폐기 정리(카드 소멸로 덱 압축).
- **패시브 "서고의 눈"**: 턴 시작 시 뽑을 더미 위 3장 보기.
- **전용 12장 스케치**: 책갈피(예약), 각주 달기, 목차 정리(덱 위 3장 순서 변경), 인용(버린 더미 카드 복사), 금서 봉인(소멸, 에너지), 낭독(각주 수만큼 피해), 개정판(카드 강화), 색인, 장서 방벽, 숙련 3장.
- **스토리 5장**: 셀레스가 새벽별을 숨긴 기록을 보관 → 루나 이야기의 "다른 쪽 기록" / 모르가나 숲의 백 년 기록 / 벨리타 계약서 사본 / 닉스의 계약 원본을 찾아 해지 조항을 발견.
- **대사**: "기록은 거짓말을 안 해. 사람이 할 뿐." / "이 카드는 다음 턴을 위해 아껴 둘게." / "닉스, 당신 계약서 제17조 읽어 봤어?"
- **구현 난이도**: 낮음~중간(보존·덱 위 조작 함수). 다만 화면에서 고르기 UI가 늘어 모바일 조작이 무거워질 수 있음.

## 추천: A안 마리엘 (인형사)
- 4명이 모두 "히로인 혼자 싸우는" 구조라 **화면과 판단이 가장 새롭게 달라지는 건 소환**. 군단/희생/한 체 강화 세 방향이 서로 다른 덱을 만들고, 기존 공용 카드와도 다르게 섞임.
- 2막 적 클로에(인형술사)·적 `puppet` 소환 로직, 아리아의 루벨 마을, 유키 2장의 목각 인형이 이미 있어 스토리 연결이 자연스러움.
- 단점은 구현량. 실제로 넣는다면 순서: 엔진 `allies` + 적 공격 대상 분기 → 봇 시뮬 밸런스(목표 33~38%) → UI 배치(390×844에서 인형 3체) → 카드 12장 → 스토리/대사 → 실제 폰 테스트.
- 구현량을 줄이고 싶으면 B안(달 위상)이 차선. 상태값 하나로 새 플레이 감각이 나옴.
